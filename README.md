# septa-tracker
Pull data from SEPTA API and display on a Raspberry Pi - powered display

## Maintaining the display

- **[LAB-GUIDE.md](LAB-GUIDE.md)**: step-by-step setup on the Pi, health checks,
  temperature monitoring, and how to push new code to the display.
- **[COMMANDS.md](COMMANDS.md)**: every command you need, on the Pi and over
  SSH from a Mac.
- **[HARDWARE.md](HARDWARE.md)**: known hardware faults, measurements, and the
  parts list with reasons.
- **[rpi5/TRACKING.md](rpi5/TRACKING.md)**: how the live train tracking works.
- `pi/`: maintenance scripts that run on the Pi.
